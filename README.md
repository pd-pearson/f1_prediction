# f1_prediction

## Project
This project is a personal project by someone who is a keen F1 fan and excited to continue learning the best tools for developing ML/Data Science solutions.

I'll be building this repo out over the next few months to take data across a variety of sources that influence the F1 standings. This will include historic qualification and race data, tyre strategies, track conditions, weather conditions and team dynamics.

I'll be using Claude to help me build out this repository, to learn how I can augment my own skills as a data scientist with coding agents.

The goal is that we'll be able to use this throughout the race calendar to make predictions on the race outcomes and the world drivers and constructors championships!

Follow along for my progress!

## Running code
### Setup
Python3.13 is required for this repository, ensure pipenv is installed then run

```pipenv install```
```pipenv shell```

Also, ensure VS code is using the environment.
